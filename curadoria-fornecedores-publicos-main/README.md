# Curadoria de Fornecedores e Compras Públicas

Projeto acadêmico da disciplina de Banco de Dados II, desenvolvido em Java com Spring Boot.

O objetivo é consultar, organizar e tratar dados públicos de fornecedores relacionados às compras públicas, utilizando informações do Compras.gov.br e dados cadastrais complementares.

## Tecnologias

- Java 17
- Spring Boot
- Spring Data JPA / Hibernate
- H2
